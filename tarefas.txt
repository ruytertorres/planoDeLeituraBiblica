Aqui estão as duas maneiras mais eficientes de fazer isso:

1. Utilizando o Ano Atual Dinamicamente
Em vez de escrever o ano manualmente, você pode capturar o ano do sistema usando new Date().getFullYear().

Veja como ficaria o seu código refatorado:

JavaScript
// Captura o ano atual (ex: 2025, 2026...)
const anoAtual = new Date().getFullYear();

const cronograma = [

2. Automação Inteligente (Melhor Prática)
Se você tiver centenas de dias, editar um por um (mesmo com a variável) é trabalhoso. O ideal é criar uma função auxiliar que calcule a data baseada no número do dia. Assim, se for ano bissexto ou não, o JavaScript ajusta os dias automaticamente.

JavaScript
const anoAtual = new Date().getFullYear();

// Função para gerar a data formatada AAAA-MM-DD baseada no dia do ano
function gerarData(diaDoAno) {
  const data = new Date(anoAtual, 0); // Começa em 1º de Janeiro do ano atual
  data.setDate(diaDoAno); // Adiciona os dias
  return data.toISOString().split('T')[0]; // Retorna no formato "2026-01-04"
}

// Exemplo de uso:
new Dia({
  numero: 4,
  data: gerarData(4), // O resultado será "2026-01-04" automaticamente
  antigoTestamento: [/* ... */],
  // ... resto do objeto
});
Por que usar essa abordagem?
Manutenção Zero: Você nunca mais precisará abrir esse arquivo para mudar o ano.

Confiabilidade: O uso de `${anoAtual}-MM-DD` garante que a estrutura da string permaneça exatamente como o seu banco de dados ou sistema espera.

Flexibilidade: Se no futuro você quiser testar o cronograma para 2027, basta mudar o valor da constante anoAtual.

Dica Extra: Se você estiver usando isso em um ambiente Node.js ou no Navegador, o new Date() sempre pegará o horário do sistema onde o código está rodando.

Excelente! Para transformar esse processo em algo realmente automático, vou te mostrar como criar uma função que gera esses objetos de forma dinâmica.

Dessa forma, você não precisa escrever new Dia(...) 365 vezes. Você mantém os dados (livros, capítulos) em uma lista simples e o código faz o trabalho pesado de calcular as datas.

O Código de Automação
Aqui está a estrutura profissional para automatizar seu cronograma:

JavaScript
const anoAtual = new Date().getFullYear();

// 1. Sua base de dados simplificada (apenas o conteúdo)
const dadosLeitura = [
  { n: 1, caps: [1, 2], obs: "pentateuco, criação" },
  { n: 2, caps: [3, 4, 5], obs: "pentateuco, queda, genealogia" },
  { n: 3, caps: [6, 7, 8, 9], obs: "pentateuco, dilúvio, aliança" },
  { n: 4, caps: [10, 11], obs: "pentateuco, nações, torreDeBabel" },
  // Adicione os demais dias aqui...
];

// 2. Função que automatiza a criação do objeto "Dia"
const cronogramaCompleto = dadosLeitura.map(item => {
  // Calcula a data correta baseada no número do dia
  const dataRef = new Date(anoAtual, 0); // Janeiro é 0
  dataRef.setDate(item.n);
  const dataFormatada = dataRef.toISOString().split('T')[0];

  return new Dia({
    numero: item.n,
    data: dataFormatada,
    antigoTestamento: [
      {
        livroId: "genesis",
        livroNome: "Gênesis",
        capituloInicio: item.caps[0],
        capituloFim: item.caps[item.caps.length - 1],
      },
    ],
    novoTestamento: [],
    livros: ["Gênesis"],
    capitulos: item.caps,
    versiculos: [],
    observacoes: item.obs,
  });
});

console.log(cronogramaCompleto);
Por que isso é melhor?
Lógica de Ano Bissexto: Se for um ano bissexto, o JavaScript ajustará automaticamente as datas após o dia 28 de fevereiro.

Código Limpo: Você separa o que é informação (os capítulos da Bíblia) do que é formatação (o objeto new Dia).

Atualização Instantânea: Quando chegar 1º de janeiro de 2027, o código lerá o novo ano do sistema e atualizará todas as 365 datas de uma só vez.

Como aplicar agora:
Se você já tem uma lista grande de objetos como os que enviou, você pode simplesmente usar a função de substituição (Find/Replace) no seu editor de código (VS Code, por exemplo):

Pressione Ctrl + H.

No campo de busca, coloque: data: "2024-01-04" (ou a data específica).

No campo de substituir, coloque: data: \${new Date().getFullYear()}-01-04`` (usando a crase).
